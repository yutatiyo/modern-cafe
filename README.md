# モダンカフェ - Modern Cafe

モダンカフェの公式Webサイトです。上質なコーヒーと居心地の良い空間を提供するカフェの情報を紹介しています。

## 📋 プロジェクト概要

このプロジェクトは、モダンカフェのWebサイトです。以下の機能を備えています：

- **ホームページ** - カフェの紹介と魅力的なビジュアル
- **メニュー表示** - おすすめの商品と価格
- **アバウト** - カフェの歴史と特徴
- **お問い合わせ** - 営業時間と連絡先

## 🎨 デザイン特徴

- モダンで洗練されたデザイン
- レスポンシブデザイン対応（スマートフォン・タブレット・PC）
- スムーズなスクロール機能
- ホバーエフェクト付きメニューカード

## 📁 ファイル構成

```
modern-cafe/
├── index.html      # メインのHTMLファイル
├── styles.css      # スタイルシート
├── script.js       # JavaScriptファイル
└── README.md       # このファイル
```

## 🚀 使用方法

1. `index.html` をWebブラウザで開く
2. ナビゲーションメニューから各セクションに移動
3. メニューカードをホバーして詳細を確認

## 🛠️ 技術スタック

- **HTML5** - ページ構造
- **CSS3** - スタイリング（グリッドレイアウト、フレックスボックス対応）
- **JavaScript** - インタラクティブ機能

## 📱 レスポンシブ対応

- デスクトップ（1200px以上）
- タブレット（768px～1199px）
- モバイル（767px以下）
